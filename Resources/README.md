# Resources

Curated learning resources, documentation links, checklists, and references. Add a short note explaining why each resource is useful.

## Technical references

- [OWASP API Security Top 10 (2023)](https://api-security.owasp.org/editions/2023/en/0x00-header/) — official API risk taxonomy.
- [Postman proxy settings](https://learning.postman.com/docs/getting-started/installation/settings/proxy-settings/) — configure API client traffic for proxy-based testing.
- [Postman proxy setup guide](https://learning.postman.com/docs/getting-started/installation/proxy/) — system and custom proxy options.
- [API Security learning checklist](../API-Security/README.md) — local study notes and assessment checklist.
- [Microsoft — Best practices for securing Active Directory](https://learn.microsoft.com/en-us/windows-server/identity/ad-ds/plan/security-best-practices/best-practices-for-securing-active-directory) — least privilege, administrative hosts, and domain-controller protection.
- [Microsoft Defender for Identity — GPO security posture assessments](https://learn.microsoft.com/en-us/defender-for-identity/modified-unprivileged-accounts-gpo) — review GPOs that grant excessive access or expose credentials.
- [BloodHound official documentation](https://github.com/SpecterOps/bloodhound-docs) — graph-based identity relationship and attack-path analysis documentation.
- [Active Directory assessment learning checklist](../Active-Directory/README.md) — local inventory, privilege, ACL, GPO, trust, monitoring, and reporting reference.
