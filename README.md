## `$ daily_log_format`

Daily notes use a consistent format so progress stays clear and useful:

- **Objective:** What I set out to learn or test.
- **Work completed:** The actual lab, challenge, exercise, or research performed.
- **Tools & techniques:** Tools, commands, and methods used where relevant.
- **Key learning:** What I understood or discovered.
- **Next step:** A concrete follow-up task.

See [Daily-Logs/README.md](Daily-Logs/README.md) for the logging guide and entry template.

## `$ principles`

1. Document only work that was actually completed.
2. Keep testing within authorized labs, CTF environments, or explicitly permitted scopes.
3. Never publish credentials, tokens, private data, or sensitive client information.
4. Explain the reasoning and evidence—not just the commands.
5. Record mistakes and lessons as well as successful results.
6. Prefer meaningful updates over artificial daily commits.
