# Daily Logs

This folder contains dated notes about genuine cybersecurity learning and hands-on work.

## Entry format

Create one Markdown file per day using `YYYY-MM-DD-topic.md`.

```markdown
# YYYY-MM-DD — Topic

## Objective
What did I plan to learn or test?

## Work completed
What did I actually do? Include the lab or CTF name when safe to disclose.

## Tools and techniques
List relevant tools, commands, and methods. Remove secrets and sensitive target data.

## Key learning
What did I understand, validate, or struggle with?

## Next step
What is the next practical action?
```

## Logging rules

- No fabricated activity, results, flags, rankings, or achievements.
- Do not publish credentials, tokens, personal data, client data, or out-of-scope details.
- Redact target identifiers and sensitive evidence from professional engagements.
- A short, honest note is better than a padded entry.
- Skipping a day is acceptable. Do not create empty commits to simulate consistency.
